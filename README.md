# Music Streaming Analysis Using Spark Structured APIs

## Overview
This project implements **Hands-on L6: Spark Structured API** for the course *Cloud Computing for Data Analysis (ITCS 6190/8190, Fall 2025, Prof. Marco Vieira)*.  
The objective is to analyze user listening behavior and music trends using **PySpark Structured APIs**, processing structured data from a fictional music streaming platform.

Key insights derived include:
- User favorite genres
- Average listening time per song
- Genre loyalty scores
- Identification of “night owl” users

---

## Dataset Description

Two input CSVs are used (generated via `datagen.py`):

1. **listening_logs.csv**  
   - `user_id` – unique user identifier  
   - `song_id` – unique song identifier  
   - `timestamp` – datetime when the song was played (e.g., `2025-03-23 14:05:00`)  
   - `duration_sec` – duration of listening in seconds  

2. **songs_metadata.csv**  
   - `song_id` – unique song identifier  
   - `title` – song title  
   - `artist` – artist name  
   - `genre` – music genre (Pop, Rock, Jazz, Classical, Hip-Hop, …)  
   - `mood` – mood category (Happy, Sad, Energetic, Chill, …)  

Datasets contain at least **100 records** to ensure sufficient analysis.

---

## Tasks and Outputs

1. **User’s Favourite Genre**  
   - Identifies each user’s most listened-to genre.  
   - Output → `outputs/user_favorite_genres/`

2. **Average Listen Time per Song**  
   - Computes mean `duration_sec` per song.  
   - Output → `outputs/avg_listen_time_per_song/`

3. **Genre Loyalty Score**  
   - Ratio: *plays of user’s top genre / total plays*.  
   - Includes subset of users with **loyalty score > 0.8**.  
   - Output →  
     - `outputs/genre_loyalty_scores/` (all)  
     - `outputs/genre_loyalty_scores/above_0_8/`  

4. **Night Owl Users**  
   - Detects users who frequently listen between **00:00–05:00**.  
   - Criteria: ≥5 plays and ≥30% of their total plays.  
   - Output →  
     - `outputs/night_owl_users/all_user_night_stats/`  
     - `outputs/night_owl_users/frequent/`

## Execution Instructions

### Prerequisites
Ensure the following are installed and properly configured:

1. **Python 3.x**  
   - [Download Python](https://www.python.org/downloads/)  
   - Verify:  
     ```bash
     python3 --version
     ```

2. **PySpark**  
   - Install via pip:  
     ```bash
     pip install pyspark
     ```

3. **Apache Spark**  
   - [Download Spark](https://spark.apache.org/downloads.html)  
   - Verify installation:  
     ```bash
     spark-submit --version
     ```

---

### 1. Generate Input Data
Run the input generator to produce `inputs/listening_logs.csv` and `inputs/songs_metadata.csv`:

```bash
python3 datagen.py
```

---

### 2. Run the Analysis
Submit the Spark job:

```bash
spark-submit main.py --input_dir inputs --output_dir outputs
```

---

### 3. Verify Outputs
Check the `outputs/` directory:

```bash
ls -R outputs/
```

---

## Errors and Resolutions
- **Error: `ModuleNotFoundError: No module named 'pyspark'`**  
  → Run `pip install pyspark`.  

- **Error: `spark-submit: command not found`**  
  → Ensure Apache Spark is installed and added to `PATH`.  

- **Error writing outputs (`Permission denied`)**  
  → Verify that the `outputs/` folder is writable or delete old outputs before rerunning.
