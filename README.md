## Overview
In this hands-on assignment, we use **GitHub Codespaces** and **Spark Structured APIs** to analyze user listening behavior and music trends. The analysis is based on structured datasets generated by the provided synthetic data generator.

The main objective is to process structured data from a fictional music streaming platform to gain insights into:
- **Genre preferences**  
- **Song popularity**  
- **Listener engagement**

---

## Learning Goals
- **Data Loading and Preparation:** Import and preprocess CSV data using Spark Structured APIs.  
- **Data Analysis:** Apply filtering, aggregation, joins, and transformations to explore user behavior.  

---

## Dataset Description
Two CSV files are used (generated with `datagen.py`):

1. **listening_logs.csv**  
   - `user_id`, `song_id`, `timestamp`, `duration_sec`  

2. **songs_metadata.csv**  
   - `song_id`, `title`, `artist`, `genre`, `mood`  

Each dataset contains at least **100 records**.

## Tasks and Outputs

### Task 1 – User’s Favourite Genre
Identifies the most listened-to genre for each user.  
**Sample Output:**
```
user_id,genre,plays
user_1,Rock,12
user_2,Pop,15
user_3,Jazz,7
```

### Task 2 – Average Listen Time per Song
Computes mean `duration_sec` grouped by song.  
**Sample Output:**
```
song_id,title,artist,genre,avg_listen_time_sec
song_1,Title_song_1,Artist_3,Pop,180.5
song_2,Title_song_2,Artist_7,Rock,210.3
```

### Task 3 – Genre Loyalty Score
Calculates proportion of plays in the user’s top genre.  
**Sample Output (all users):**
```
user_id,fav_genre,fav_genre_plays,total_plays,loyalty_score
user_1,Rock,12,15,0.80
user_2,Pop,20,22,0.91
```
Users with loyalty score > 0.8 are saved in `above_0_8/`.

### Task 4 – Night Owl Users
Detects users who frequently listen between **00:00–05:00**.  
**Sample Output:**
```
user_id,night_plays,total_plays,night_ratio
user_5,8,20,0.40
user_8,12,30,0.40
```

## Execution Instructions

### Prerequisites
1. **Python 3.x**  
   ```bash
   python3 --version
   ```

2. **PySpark**  
   ```bash
   pip install pyspark
   ```

3. **Apache Spark**  
   ```bash
   spark-submit --version
   ```

---

### 1. Generate Input Data
```bash
python3 datagen.py
```

### 2. Run the Analysis
```bash
spark-submit main.py --input_dir inputs --output_dir outputs
```

### 3. Verify Outputs
```bash
ls -R outputs/
```

---

## Errors and Resolutions
- **Missing pyspark** → Run `pip install pyspark`  
- **spark-submit not found** → Ensure Apache Spark is installed and added to PATH  
- **Permission denied writing outputs** → Delete existing outputs or check folder permissions
